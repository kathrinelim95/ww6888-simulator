Telegram Betting — Simulation Reference

This page documents the Telegram betting workflow observed on the reference platform. In this simulator, Telegram integration is not connected to any real messaging service.

How it works

  1. Edit the phone number in the downline list or profile.
  2. Add the service's Telegram bot to contacts.
  3. Confirm the phone number.
  4. Submit bets via Telegram message.

Bet message format

UserID Day 4DNumber B-S

  • Day: 0=Wed/Sat/Sun, 2=Sat/Sun, 3=Wed, 6=Sat, 7=Sun
  • 4D: Normal (1234), iBet (1234i), Roll (1234r), kBet (1234k), Wildcard (123*)
  • B-S: 1-=1 Big, -1=1 Small, h-=0.5 Big, q-=0.25 Big

Confirmation

Bets are confirmed only when a reply message with the total amount is received. If no reply within 1 minute, send "last bet" to retry.
